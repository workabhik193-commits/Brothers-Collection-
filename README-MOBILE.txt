BROTHERS COLLECTION — MOBILE SETUP (FREE)

WHAT YOU GET
- Original responsive fashion storefront
- Sample clothing product cards and category filters
- Add-to-bag cart, quantity controls and subtotal
- WhatsApp order message builder
- No paid platform or coding software required
- These are sample products/prices. Replace them before selling.

IMPORTANT: SET YOUR WHATSAPP NUMBER
1. Open script.js in a text editor.
2. Near the top, find:
   const WHATSAPP_NUMBER = "91XXXXXXXXXX";
3. Replace with your WhatsApp number including country code, digits only.
   Example format for an Indian number: "919876543210"
   Do not use +, spaces or dashes.
4. Save script.js.

EDIT PRODUCTS
In script.js, find the `const products = [` section.
Change each product's name, category, price, description and tag.
Available categories: "T-Shirts", "Shirts", "Hoodies", "Bottomwear".
The illustrations are placeholders, not real product photos. For real product photos,
you can replace each product image area with your own hosted image later or ask for
help adding images.

FREE PUBLISHING WITH GITHUB PAGES — PHONE
A. On Chrome, open https://github.com and create/sign in to an account.
B. Create a new public repository named `brothers-collection`.
C. Upload the three website files: index.html, style.css, script.js.
   Also upload README-MOBILE.txt if you want to keep the instructions in the repo.
D. In your repository, open Settings → Pages.
E. Under Build and deployment, select “Deploy from a branch”.
F. Choose branch `main`, folder `/(root)`, then Save.
G. Wait a few minutes. The site URL will look like:
   https://YOUR-USERNAME.github.io/brothers-collection/
   Use the exact URL GitHub Pages shows you.
H. Open the URL on your phone and test adding items to the cart and the WhatsApp button.

PHONE TIP
GitHub's upload and file-editing screens can be fiddly on mobile. In Chrome's three-dot
menu, try “Desktop site” if needed. Do not upload your WhatsApp number publicly if you
do not want it visible; it is used by the storefront's WhatsApp links.

BEFORE LAUNCH
- Replace sample products and prices with real, accurate information.
- Set the correct WhatsApp number.
- Test the WhatsApp order on your own phone.
- Add delivery, returns, sizing and contact details.
- Do not collect customers' card details in this static site.
- GitHub Pages is static hosting; this site does not include user accounts, inventory
  sync, a payment gateway, or automatic shipping integration.
